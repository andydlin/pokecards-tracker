# Pokecards Tracker — Pokémon Price Watch

Daily eBay lowest-price tracking for 11 Simplified Chinese Pokémon TCG cards (12 tracked series, incl. the Eevee ex single and 2-card set tracked separately).

- Lowest active eBay prices checked daily (~9:20am PT), totals include shipping
- Buy / Wait calls from raw/ungraded sold history back to Jan 2026 (PriceCharting + eBay Terapeak)
- Charizard V (cs5aC 132/127 alt art) listings are photo-verified before counting — titles lie on that card
- Open `index.html` (or the GitHub Pages site, if enabled) to view the dashboard

Updated daily by Muse. Browsing/research only — nothing is bought or bid on.
